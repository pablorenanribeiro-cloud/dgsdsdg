# 📚 Portal do Aluno (Boletim Escolar)

Este projeto foi desenvolvido como prática de Front-end, utilizando **HTML5**, **CSS3** e **JavaScript**. O objetivo é simular um portal acadêmico onde o aluno pode consultar suas informações, notas, faltas e situação escolar.

## 🚀 Tecnologias Utilizadas
* **HTML5:** Estrutura semântica (`<header>`, `<nav>`, `<main>`, etc) e acessibilidade (labels, alt).
* **CSS3:** Estilização com Flexbox e CSS Grid, cards, tabelas estilizadas, responsividade via `@media` queries.
* **JavaScript:** Manipulação de DOM para calcular médias, verificar status de aprovação (Aprovado, Recuperação, Reprovado) e cálculo de frequência.

## ⚙️ Funcionalidades Implementadas
1. **Dados do Aluno:** Exibição estruturada das informações.
2. **Tabela de Histórico:** Consulta rápida das notas por bimestre.
3. **Simulador de Resultados (Calculadora):** * Cálculo dinâmico da Média (3 bimestres).
   * Validação de situação escolar.
   * Cálculo de frequência baseado em faltas.
4. **Cards Resumo & Avisos:** Interface amigável tipo *Dashboard*.
